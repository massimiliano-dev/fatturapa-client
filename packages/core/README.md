# @massimiliano-dev/fatturapa-core

Core of [fatturapa-client](https://github.com/massimiliano-dev/fatturapa-client): typed FatturaPA model
(schema 1.2.3), XML builder and parser, exact decimals, `computeTotals`, `checkBusinessRules` (SDI rejection
codes), code tables generated from the official XSD, SDI notifications, `.p7m` extraction, file names,
the `SdiProvider` interface, a hardened HTTP client and `redact()`.

Unofficial. See the repository README and SECURITY.md.
